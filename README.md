# SafeSpace

Smart Personal Safety & Emergency Assistance Platform

## Overview
SafeSpace is a web application built for personal safety. It allows users to quickly trigger an SOS, access emergency contacts, and share their location.

## File Structure
- `index.html`: Main UI
- `css/`: Stylesheets for layout and SOS alerts
- `js/`: Modular JavaScript files handling API, DOM, geolocation, XML, and storage
- `data/`: Sample XML safety profiles
- `assets/`: Icons and images
- `libs/`: Local library fallbacks
